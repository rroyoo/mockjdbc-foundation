# Functional Documentation

This folder contains concise functional documentation for user-visible behavior.

## Scope
- Functional flows and use cases.
- Expected inputs/outputs.
- Behavior-focused constraints and edge cases.

## Conventions
- Keep content clear and short.
- Prefer bullets over dense paragraphs.
- Add small examples when they remove ambiguity.
- Add simple diagrams only when they clarify a flow.
- Use tables for grouped properties, fields, and option sets.
